Положите сюда реальные фотографии (JPG/PNG/WebP, желательно от 1600 px по длинной стороне):

hero, about, red-romance, pink-dream, white-elegance, summer-mood, royal-roses, tenderness

Затем выполните: npm run images
Скрипт обрежет их до 4:5 и сохранит оптимизированные WebP в src/assets/images/.
Сейчас в src/assets/images/ лежат стилизованные иллюстрации-заглушки, а не фотографии.
